# Tempo Bench

เมโทรนอมบนเว็บที่ตั้งค่าได้ละเอียด ไฟล์เดียว ไม่ต้อง build

- BPM 20–400 ละเอียดถึงทศนิยม, Tap tempo, ชื่อเทมโป (Largo → Prestissimo)
- กำหนดน้ำหนักทีละจังหวะ (เน้น / ปกติ / เบา / เงียบ), time signature 1–16 / 2,4,8,16
- ซอยโน้ต 1–8, swing 50–75%, polyrhythm
- เสียง Click / Woodblock / Beep / Cowbell / Hi-hat, ปรับความดังและ pitch แยกชั้น
- ฝึกซ้อม: ไต่ความเร็ว, gap click, สุ่มเงียบ, นับนำ, ตั้งเวลาหยุด
- พรีเซ็ต (เก็บใน localStorage)
- ส่งออก click track เป็น **WAV** (16-bit mono, 44.1/48 kHz) และ **MIDI** (ช่อง 10, มี tempo map และ time signature) จากค่าที่ตั้งไว้ทั้งหมด รวมโครงเพลงและการไต่ความเร็ว ใช้เป็น click source ใน DAW ได้

### โหมด Advance

เปิดสวิตช์ **โหมด Advance** มุมขวาบน แต่ละแท็บจะกางส่วนขั้นสูงเพิ่ม (มีป้าย ADVANCE) ถ้าปิดสวิตช์ ทุกอย่างจะกลับไปทำงานแบบปกติ (ค่าที่ตั้งไว้ยังเก็บอยู่) ปุ่ม **คืนค่าเริ่มต้น** ล้างการตั้งค่ากลับเป็นค่าเริ่มต้น (พรีเซ็ตและสถิติยังอยู่)

- แท็บจังหวะ: หน่วยของ BPM รวมโน้ตประจุด (♩. ♪. 𝅗𝅥.) และคลิกตามหน่วย เช่น 6/8 ที่ ♩. = 60 ได้ 2 คลิกต่อห้อง
- แท็บจังหวะ: กริดจังหวะ — ซอยแยกรายจังหวะ และเปิด/ปิดโน้ตย่อยทีละตัว (ประจุด, gallop, syncopation) พร้อมแพทเทิร์นสำเร็จรูป
- แท็บฝึกซ้อม: โครงเพลง — เล่นท่อนต่อกัน แต่ละท่อนกำหนดจำนวนห้อง ห้องจังหวะ และ BPM เองได้ วนซ้ำหรือหยุดเมื่อจบ
- แท็บเสียง: เลื่อนภาพชดเชยความหน่วงของหูฟังบลูทูธ และโหมดดูภาพอย่างเดียว
- แท็บฝึกซ้อม: สถิติการซ้อม — วันนี้, 7 วันล่าสุด, จำนวนวันต่อเนื่อง

คีย์ลัด: `Space` เล่น/หยุด · `↑` `↓` ±1 BPM (`Shift` ±10) · `T` แตะจังหวะ

เสียงสร้างด้วย Web Audio API และตั้งเวลาล่วงหน้า (lookahead scheduler) ผ่าน Web Worker เพื่อให้จังหวะแม่นแม้แท็บอยู่เบื้องหลัง

## ซ้อมกับเพลง (Song Lab)

กด **ซ้อมกับเพลง** ใต้ชื่อแอป (หรือเปิดลิงก์ที่ลงท้าย `#song`) แล้วเลือกไฟล์:

- **ไฟล์เสียง** (mp3, wav, m4a, ogg, flac): ตั้ง BPM (พิมพ์, TAP ตามเพลง, ÷2 / ×2), ห้องจังหวะ และจุดเริ่มห้อง 1 (พิมพ์วินาที, ปรับทีละ 1/10 ms, แตะบนคลื่นเสียงที่ซูมไว้ หรือกดตั้งตรงตำแหน่งที่กำลังเล่น) ตั้ง BPM / ห้องจังหวะแยกเป็นช่วงได้สำหรับเพลงที่เปลี่ยนความเร็วกลางเพลง
- **Guitar Pro** (gp, gpx, gp3–gp5) อ่านด้วย [alphaTab](https://alphatab.net) 1.8.4 (vendored ที่ `vendor/`, MPL-2.0) ได้ห้องจังหวะ, tempo และชื่อท่อนจากไฟล์ เล่นตามเครื่องหมายวนซ้ำและ alternate ending ได้ (ปิดได้)
- **MIDI** (mid): อ่าน tempo map, time signature และ marker เป็นชื่อท่อน

จากนั้นเลือกช่วงห้องในแผนที่ห้อง (แตะห้องแรกแล้วแตะห้องสุดท้าย, ลากเมาส์, Shift+คลิก, ปุ่มชื่อท่อน หรือพิมพ์ จาก–ถึง) แล้วตั้งคลิกของช่วงนั้น: ปิดคลิก, เน้นจังหวะแรก, ซอยโน้ต 2–8, แพทเทิร์น (ประจุด, gallop, …), swing และห้องผสม x/8 คลิกทุก ♩.

ตั้งการซอยได้สองระดับ:

- **รายห้อง:** เลือกการซอยหรือแพทเทิร์นให้ทุกจังหวะในห้องที่เลือก
- **รายจังหวะ:** เลือกห้องเดียว (หรือหลายห้องที่มีจำนวนจังหวะเท่ากัน) แล้วตั้งการซอยของแต่ละจังหวะและเปิด/ปิดโน้ตทีละตัว รวมถึงตัวจังหวะเอง ห้องที่ตั้งแบบนี้มีป้าย "กริด" ในแผนที่ห้อง

**คลิกตามโน้ตในไฟล์** (Guitar Pro / MIDI): ให้คลิกตรงจุดเริ่มของโน้ตในแทร็กที่เลือก ใช้ *แทนคลิกจังหวะ* หรือ *เพิ่มจากคลิกจังหวะ* ก็ได้ ตั้งเป็นรายห้อง เหมาะกับซ้อมริฟฟ์ที่จังหวะซับซ้อน

ปุ่ม **คืนค่าเริ่มต้น** มุมขวาบน ถ้ากดตอนอยู่ในโหมดนี้ จะล้างการตั้งค่าของเพลงที่เปิดอยู่ (คลิกรายห้อง, BPM / จุดเริ่มห้อง 1, ช่วงที่เลือก, การปิดเสียงแทร็ก) โดยไม่กระทบค่าของหน้าเมโทรนอม

เล่นพร้อมเพลง (ปรับความดังเพลง/คลิกแยกกัน) วนช่วงที่เลือก นับนำ 1 ห้อง และส่งออก click track **เฉพาะห้องที่เลือก** เป็น WAV หรือ MIDI (มี tempo map, time signature และ marker) โดยเลือกได้ว่าไฟล์เริ่มที่ต้นเพลง (วางที่ 0 ใน DAW ได้เลย) หรือเริ่มที่ห้องแรกของช่วง

**เสียงโน้ตจากไฟล์ Guitar Pro / MIDI:** เล่นโน้ตจริงจากไฟล์ไปพร้อมคลิก ใช้ชุดเสียงเดียวกับ [Riff Forge](https://github.com/un4ckn0wl3z/riff-forge) เพื่อให้สองโปรแกรมเสียงตรงกัน: กลองและเบส picked จาก sample SONiVOX EAS (ที่ `samples/`, Apache-2.0 ดู `samples/LICENSE.txt` และ `samples/SOURCE.md`) กีตาร์เป็นเสียงอ้างอิงแบบเดียวกับ Riff Forge ส่วนเครื่องดนตรีอื่นใช้เสียงสังเคราะห์ตามกลุ่ม General MIDI โน้ตกลอง GM ที่ไม่มี sample ตรงตัวจะใช้ sample ที่ใกล้ที่สุด มีปุ่มแทร็กให้ปิดเสียงส่วนที่จะเล่นเอง ปรับความดังโน้ตแยกจากคลิก และเลือกใส่เสียงโน้ต (เฉพาะแทร็กที่เปิดอยู่) ลงในไฟล์ WAV ที่ส่งออกได้ ไฟล์ Guitar Pro ใช้โน้ตจากตัวสร้าง MIDI ของ alphaTab จึงเล่นตาม repeat ได้ถูกห้อง

ข้อจำกัด: ไฟล์เสียงใช้ BPM คงที่ต่อช่วง เพลงที่อัดสดโดยไม่มีคลิกอาจค่อยๆ คลาด ยังไม่มีการหา BPM อัตโนมัติ ยังไม่เล่น bend / vibrato
